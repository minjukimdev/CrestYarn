# CrestYarn

High-performance CrestYarn leverages real-time processing and auto-scaling to optimize yarn deployment as a cloud-based resource manager and scheduler.

CrestYarn is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/CrestYarn.git`
2. `cd CrestYarn`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
